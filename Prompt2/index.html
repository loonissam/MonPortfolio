Mes Projets

Système de Télémétrie de Course

Développement d'un tableau de bord affichant les données en temps réel d'un véhicule sur piste (températures, pressions, régime moteur).
Technologies : C++, Qt, Bus CAN, Python.

Reprogrammation Moteur (ECU)

Analyse et modification des cartographies d'injection pour optimiser les performances d'un moteur thermique. Gain de puissance et de couple validé sur banc d'essai.
Outils : WinOLS, Interface OBD2.

Application 'TrackDay Manager'

Création d'une application web pour gérer ses sessions sur circuit : chronométrage GPS, historique des réglages châssis et usure des pneumatiques.
Technologies : React Native, API Google Maps.

Aérodynamique Active

Conception et programmation d'un aileron arrière dynamique s'inclinant lors des phases de freinage pour augmenter l'appui, testé sur un modèle réduit 1/8ème.
Technologies : Arduino, Impression 3D.
